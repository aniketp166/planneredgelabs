# PlannerEdge Labs

PlannerEdge Labs is the corporate home for MPSC Planner and UPSC Planner, focused digital products for competitive exam preparation in India.

This is a static, frontend-only Next.js site. It has no backend, authentication, database, API routes, CMS, analytics, forms, environment configuration, or secrets.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run lint
npm run build
npm run start
```

## Deploying to Vercel

Push this repository to a Git provider, import it into Vercel, and deploy. No environment variables or additional configuration are needed.

Canonical domain: [planneredgelabs.com](https://planneredgelabs.com)
